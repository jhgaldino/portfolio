# Portfolio - Jonathan Galdino

## Descrição
Portfólio técnico pessoal desenvolvido em HTML5, CSS3 e JavaScript puro (sem frameworks ou etapa de build), com estética inspirada em sistemas e documentação de engenharia. Disponível em português e inglês.

## Stack e Recursos
- HTML5 semântico com meta tags Open Graph e Content Security Policy
- CSS Grid / Flexbox autoral com variáveis de tema (`dark` padrão em carvão quente e `light` em papel técnico, com destaque em âmbar)
- Tipografia `IBM Plex Sans` e `IBM Plex Mono`
- Phosphor Icons e Devicon
- JavaScript vanilla para troca de idioma (PT/EN), alternância de tema com persistência em `localStorage`, currículo dinâmico por idioma e navegação responsiva
